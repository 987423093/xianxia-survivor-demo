# 修仙割草 Demo 功能模块总览与完成情况

## 1. 文档目的

本文档记录当前 HTML5 Canvas 修仙割草 Demo 的功能模块拆分、已完成范围、缺口和后续计划。当前交付目标仍是可玩的网页 Demo，Cocos Creator 原生工程暂未落地。

> 说明：本文档是模块总览。每个模块“要做成什么样、当前实现细节、验收标准、后续落地项”已经拆到 [../modules/README.md](../modules/README.md) 下的独立模块文档中。

状态定义：

| 状态 | 含义 |
| --- | --- |
| 已完成 | 已在 `demo/` 中可运行，并经过基础验证 |
| MVP | 主流程已跑通，但表现、深度或可配置性还需要加强 |
| 进行中 | 已有部分代码或素材，但还不是完整玩法 |
| 计划中 | 已明确方向，尚未实现 |
| 延后 | 当前版本不做，等 Cocos 或更大版本再处理 |

## 3. 战斗核心模块

### 3.1 玩家控制

状态：已完成

当前明细：

- 支持键盘 WASD / 方向键移动。
- 支持移动端左下角虚拟摇杆区域。
- 摄像机跟随玩家，带屏幕震动。
- 玩家有气血、移速、拾取范围、无敌时间、减伤等基础属性。

后续计划：

- 增加短冲刺/闪避，用于高难度 Boss 机制。
- 移动端摇杆加视觉底盘和触控提示。
- 不同功法或装备影响移动特效。

### 3.2 敌人与刷怪

状态：已完成

当前明细：

- 普通怪、精英怪、Boss 三类敌人。
- 敌人具备血量、速度、接触伤害、击杀反馈。
- 波次按时间触发，章节和难度会修改血量、速度、伤害、刷怪速度和上限。
- 敌人图片优先使用 image2 资源，失败时旧主题可走几何绘制。

后续计划：

- 增加章节专属普通怪和精英怪。
- 增加远程怪、冲锋怪、自爆怪、护盾怪。
- 增加怪物词缀，用于高难度变化。

### 3.3 武器与伤害

状态：已完成

当前明细：

- 飞剑自动索敌。
- 业火莲华近身范围伤害。
- 雷符万钧散射并命中爆发。
- 天劫雷瀑由灵力触发，多段随机雷击。
- 伤害受法宝、天赋树、装备和功法影响。

后续计划：

- 给法术补更多质变节点，例如飞剑穿透、火莲分裂、雷符连锁。
- 增加伤害来源统计，结算时展示最强法术。
- 增加局内法术图鉴和暂停页说明。

## 13. 建议优先级

### P0：补齐当前体验缺口

1. 数值跑测校准：记录首次升级时间、5 分钟升级次数、Boss TTK 和结算材料，反推 `balance`。
2. UI 内 debug 面板：把现有 URL/控制台调试入口收敛成可点击工具。
3. 缺材料升级提示：升级按钮旁直接提示推荐章节，而不是只在材料页展示。
4. 高难 Boss 机制差异：让玄境、天境不只是数值倍率。

### P1：提高长期目标

1. Boss 图鉴重挑战记录和失败复盘。
2. 玩家自定义构筑保存与一键切换。
3. 成长路线推荐和洗点机制。
4. 高难度专属材料与掉落图标。

### P2：扩展玩法深度

1. 材料合成/兑换。
2. 局内材料掉落。
3. 设施外观升级。
4. 章节星级、挑战目标和更多稀有奇遇链。
