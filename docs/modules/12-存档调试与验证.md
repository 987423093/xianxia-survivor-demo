# 12 存档、调试与验证

## 目标形态

这个模块保障 Demo 可持续迭代：存档不丢、调试方便、改完能快速验证。

## 当前实现

状态：MVP

当前存档：

- 使用 `localStorage`。
- key：`xianxia-survivor-meta-v1`。
- 保存资源、解锁、当前选择、成长等级、章节记录。

当前存档工具：

- 洞府底部已增加存档导出/导入按钮和文本框。
- 导入时走 `sanitizeMetaState()`，避免把异常字段直接写回存档。

当前验证：

- `node --check` 覆盖 `demo/src/*.js` 和验证脚本。
- `npm run config:check` 检查关键 UI 钩子和配置接线。
- `npm run test:meta` 检查材料配置、难度倍率、升级成本和章节收益覆盖。
- `npm run assets:check` 检查资产尺寸和 alpha。
- `npm run smoke` 检查默认页、旧主题、Boss debug 路由和关键静态资源。
- 浏览器级人工验证已覆盖材料页桌面/移动端缺口场景。
- 浏览器级人工验证已覆盖奇遇分支、隐藏连锁未发现/已发现两种状态。

## 当前缺口

- 没有 UI 内 debug 面板。
- 还没有局内行为级自动化，例如真正点升级按钮后的扣费回归。
- 奖励公式和奇遇触发目前仍以配置/静态断言为主，还没有完整战斗回放测试。
- 还没有固定的浏览器截图基线产物。
- URL 和控制台调试能力已经比较多，但入口分散，维护成本开始变高。

## 后续计划

- 新增 debug 面板，支持发材料、解锁章节、直跳 Boss。
- 新增奇遇链和隐藏连锁的浏览器回归脚本。
- 增加升级扣费和关键局外按钮流的浏览器回归脚本。
- 增加 Boss debug 场景和材料页的截图基线。
- 给存档导入补成功/失败样例和回滚策略说明。
- 整理调试入口索引，避免新增场景继续堆 URL 参数。

## 验收标准

- 改动后能一键跑语法、配置、资产和 smoke 检查。
- 默认主题和旧主题都能打开。
- 局外存档刷新不丢。
- 存档可以导出并重新导入。
- 调试接口能快速复现 Boss、装备、境界和指定奇遇链状态。
