## 状态口径

- 已完成：当前 Demo 中已经可玩或可用，且经过基础验证。
- MVP：主流程已经跑通，但表现、引导、数值深度或工具化还不够。
- 计划中：已经明确方向，尚未实现。
- 延后：当前网页 Demo 不做，等 Cocos 或更大版本处理。
