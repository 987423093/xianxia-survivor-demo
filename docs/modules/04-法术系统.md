# 04 法术系统

## 目标形态

法术系统负责局内爽感和流派区分。法术不是单纯换子弹皮肤，而应该有不同攻击区域、节奏和强化方向。

## 当前实现

状态：已完成

当前法术：

| 法术 | 当前定位 | 当前效果 |
| --- | --- | --- |
| 御剑成阵 | 基础索敌 | 自动索敌发射飞剑 |
| 业火莲华 | 近身范围 | 周期性环形灼烧 |
| 雷符万钧 | 散射爆发 | 符箓散射，命中造成伤害 |
| 天劫雷瀑 | 大招 | 灵力满后自动多段落雷 |

当前能力：

- 法术可以通过局内升级解锁和强化。
- 法宝、功法、天赋树、装备可以影响法术。
- 天劫雷瀑使用独立灵力条。

## 数据结构

主题字段：

| 字段 | 用途 |
| --- | --- |
| `spells.keyboard` | 御剑成阵配置 |
| `spells.coffee` | 业火莲华配置，沿用早期内部命名 |
| `spells.invoice` | 雷符万钧配置，沿用早期内部命名 |
| `spells.ultimate` | 天劫雷瀑配置 |
| `upgrades` | 法术升级项 |

局内字段：

| 字段 | 用途 |
| --- | --- |
| `game.weapons` | 法术/武器运行态 |
| `game.energy` | 灵力值和获取倍率 |
| `game.ultimate` | 大招伤害 |
| `game.spellPowerBonus` | 通用法术伤害加成 |

## 交互设计

- 玩家不手动施法，降低操作负担。
- 法术升级通过突破卡牌选择。
- 天劫雷瀑自动释放，作为高频爽点。
- 不同法术要通过视觉、范围和节奏区分。

## 当前缺口

- 法术质变节点还少。
- 法术组合还没做。
- 没有法术详情页。
- 内部 key 仍保留 `coffee`、`invoice`，UI 已转中文但代码语义后续可整理。

## 后续计划

- 御剑成阵：多剑、穿透、回旋剑阵。
- 业火莲华：旋转火莲、火种扩散、灼烧叠层。
- 雷符万钧：雷爆范围、连锁、定身。
- 天劫雷瀑：雷劫层数、锁定 Boss、雷池联动。

## 验收标准

- 每个法术至少有独立视觉资源。
- 法术升级后玩家能明显感知变化。
- 灵力满后能自动释放大招。
- UI 不暴露内部字段名。
