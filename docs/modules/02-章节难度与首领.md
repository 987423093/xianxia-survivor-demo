# 02. 章节、难度与首领

## 1. 目标形态

章节模块负责长期目标和刷图路线，Boss 模块负责每章记忆点，难度模块负责重复挑战。三者合在一起决定玩家为什么要反复开局。

## 3. 数据结构

### 3.1 章节配置字段

| 字段 | 用途 |
| --- | --- |
| `id` / `name` / `desc` | 章节基础信息 |
| `background` | 地图资源 |
| `unlock` | 解锁条件 |
| `enemyMods` | 章节敌人修正 |
| `spawnMods` | 章节刷怪修正 |
| `rewardMultiplier` | 章节奖励倍率 |
| `bossAt` | Boss 出现时间 |
| `bossName` / `bossAsset` | Boss 展示 |
| `bossMechanics` | Boss 技能机制 |
| `firstClearUnlocks` | 首通解锁 |
| `drops` | Boss 掉落材料 |
| `runEvents` | 本章局内奇遇配置 |

### 3.2 Boss 技能配置字段

| 字段 | 用途 |
| --- | --- |
| `shape` | circle / line / cone / pool / pull / ring / summon |
| `cooldown` | 技能冷却 |
| `telegraph` | 预警时间 |
| `damage` | 伤害 |
| `phase` | 最低阶段 |
| `pattern` | 组合表现 |
| `duration` | 持续留场 |
| `followup` | 后续技能 |

### 3.3 章节奇遇配置字段

| 字段 | 用途 |
| --- | --- |
| `kind` / `label` / `summary` | 奇遇基础表现 |
| `choices` / `choicesByDifficulty` | 可选分支 |
| `blessing` | 临时加持 |
| `followupEventId` | 常规连锁后续 |
| `secretFollowup` | 隐藏稀有后续 |
| `ambushByDifficulty` | 伏击怪配置 |
| `challengeByDifficulty` | 限时试炼配置 |

## 4. 交互设计

- 章节卡显示地图缩略图、Boss、最佳记录、难度按钮、章节收益、首通奖励和奇遇预览。
- 锁定章节变灰但保留可见，制造目标感。
- Boss 技能必须先预警再伤害。
- Boss 击败是本局通关和局外解锁的关键节点。
- 奇遇路线默认只透出常规信息，隐藏连锁在未发现前不直接透出真实名称。
- Boss 出场时间、目标击杀时间、章节难度倍率后续统一按 [05-数值管理模块](./05-数值管理模块.md) 校准。

## 5. 当前缺口

- 难度主要是数值变化，机制差异还不够。
- 隐藏连锁和当前构筑的推荐关系还没做。
- Boss 图鉴已有入口，但还缺少独立的重挑战记录和更完整的战斗复盘。

## 6. 后续计划

- 扩展 Boss 图鉴的重挑战记录、最优构筑和失败原因复盘。
- 高难度加入 Boss 组合技和专属掉落。
- 继续扩每章 1-2 条稀有奇遇链。
- 给章节卡补未见奇遇/未触发连锁提示。

## 7. 验收标准

- 四个章节都能进入。
- Boss 按章节正确出现。
- Boss 预警可读，不能无提示伤害。
- 首通能解锁后续内容。
- 章节奇遇能正确触发分支、伏击、试炼和连锁。
- 隐藏连锁未发现前不剧透，发现后进入图鉴。
- `?debugBoss=1&chapter=...` 能快速验证 Boss。
- 图鉴页能查看 Boss 技能、掉落、首通奖励并跳转到挑战构筑。
