# 07 洞府局外 UI

## 目标形态

洞府 UI 是局外成长入口，要让玩家感觉是在经营自己的修仙洞府，而不是打开一堆通用后台卡片。

目标体验：

- 打开游戏先看到洞府。
- 能明确看到当前资源、章节、构筑和成长入口。
- 每个页签有专属插画和图标。
- 操作密度足够高，不做营销式落地页。

## 当前实现

状态：MVP

当前页签：

| 页签 | 当前内容 |
| --- | --- |
| 章节 | 章节选择、难度选择、记录、掉落、首通奖励、推荐流派、战备评估 |
| 开局 | 本命法宝、初始天赋、起手功法、构筑预设、本章策令、入局预览 |
| 历练 | 章节路线、悬赏进度、成长目标、奇遇图鉴、合术路线、下一步建议 |
| 材料 | 材料余额、短期缺口、推荐刷图路线 |
| 悬赏 | 悬赏进度与领取 |
| 图鉴 | Boss 技能、章节机制、掉落首通、组合与路线辅助入口 |
| 天赋 | 五条天赋树 |
| 法宝 | 六件本命法宝升级和选择 |
| 功法 | 四本起手功法 |
| 洞府 | 六个设施升级 |

当前视觉：

- 洞府背景图。
- 多张页签横幅。
- 法宝、设施、方向图标。
- 半透明墨色/玉牌风格面板。
- 历练页已补路线面板、推荐卡和奇遇图鉴列表。
- 章节、图鉴和开局页已接入 reward chip、style tag、里程碑、预设和战备条等信息组件。

## 当前缺口

- 卡片信息层级还可以继续优化。
- 移动端只是适配，没有专门交互设计。
- 图鉴页、历练页、章节页之间还有少量信息重复。
- 页签内容变多后，需要继续压缩首屏信息密度，避免移动端滚动过长。

## 后续计划

- 调整图鉴、历练、章节三处的信息边界。
- 增加每个页签的空状态和满级状态表现。
- 增加构筑和奇遇分支的联动推荐。
- 移动端改成底部 tab 或更大的触控目标。

## 验收标准

- 默认打开显示洞府。
- 主要页签都能切换。
- 图片无破图。
- 资源和按钮不重叠。
- 推荐入口、材料聚焦和奇遇路线能跳转到对应页签。
- 旧主题不显示洞府且不报错。
