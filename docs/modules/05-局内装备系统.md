# 05 局内装备系统

## 目标形态

局内装备用于让每局成长不只增加攻击，还能改变角色外观和属性。它是单局内的装备，不等同于局外本命法宝。

## 当前实现

状态：已完成

装备槽：

| 槽位 | 当前作用 | 视觉层级 |
| --- | --- | --- |
| 法袍 | 气血上限 | 主角躯干叠加 |
| 法冠 | 灵力获取 | 头顶叠加 |
| 靴子 | 移速 | 脚下/底层特效 |
| 护符 | 拾取或减伤 | 身侧悬浮 |
| 法器 | 法术伤害 | 右侧悬浮 |

当前能力：

- 每槽 0-3 阶。
- 升级三选一中会出现装备卡。
- 选择装备后立即刷新外观。
- 装备按独立锚点渲染，不再全部糊在主角中心。

## 数据结构

主题字段：

| 字段 | 用途 |
| --- | --- |
| `equipmentSlots` | 槽位名称、最大阶数、图片、锚点、缩放、层级 |
| `equipmentUpgrades` | 装备升级卡池 |

局内字段：

| 字段 | 用途 |
| --- | --- |
| `game.equipment[slot].tier` | 当前槽位阶数 |
| `drawPlayerEquipmentLayers()` | 按层级绘制装备 |

## 交互设计

- 升级卡显示“装备”标签。
- 同槽重复选择会升阶。
- 三阶视觉更亮，有脉冲或外圈。
- 装备不覆盖主体，只作为局部增强。

## 当前缺口

- 装备没有套装效果。
- 装备和本命法宝联动较弱。
- 装备不掉落，只通过升级卡获得。

## 后续计划

- 增加套装效果。
- 增加装备流派标签。
- 让部分 Boss 或章节影响装备出现概率。

## 验收标准

- 每个槽位至少有 3 阶图。
- 装备选择后外观立即变化。
- 装备和境界图同时可见。
- 小尺寸战斗中法器、护符、法冠能辨识。
