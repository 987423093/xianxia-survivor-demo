# 08 开局构筑

## 目标形态

开局构筑让玩家在入局前做少量高价值选择，形成“这一局我想走什么流派”的预期。

目标体验：

- 选择一件本命法宝。
- 选择若干初始天赋。
- 选择一本起手功法。
- 入局后马上感受到选择差异。

## 当前实现

状态：MVP

当前构筑项：

| 类型 | 当前数量 | 当前规则 |
| --- | ---: | --- |
| 本命法宝 | 6 | 选择 1 件 |
| 初始天赋 | 12 | 默认 1 槽，设施升级增加到 3 槽 |
| 起手功法 | 4 | 选择 1 本 |
| 构筑预设 | 3 | 按章节推荐，可套用已解锁组件 |

默认选择：

- 本命法宝：青冥剑匣或默认可用法宝。
- 初始天赋：默认天赋中的第一个。
- 起手功法：御剑诀。

## 数据结构

存档字段：

| 字段 | 用途 |
| --- | --- |
| `metaState.selected.artifactId` | 当前本命法宝 |
| `metaState.selected.startingTalentIds` | 当前初始天赋 |
| `metaState.selected.cultivationId` | 当前起手功法 |

应用流程：

1. `resetGame()` 初始化本局。
2. `applyMetaProgressionToRun()` 读取局外选择。
3. 本命法宝、功法、天赋树、设施效果应用到 `game`。
4. 战斗开始。

## 交互设计

- 开局页展示当前构筑摘要。
- 锁定项不可选。
- 本命法宝和功法使用图标 chip。
- 天赋槽数量显示为 `当前/上限`。
- 已增加入局预览，展示输出、生存、成长和总战备评估。
- 已增加本章策令，会根据章节 Boss 机制推荐法宝、功法和天赋。
- 已增加构筑预设和流派标签，支持飞剑、灵火、雷符、生存、成长、控场等方向。
- 已增加短板补齐动作，能按当前章节需求自动补输出、生存或成长短板。

## 当前缺口

- 目前是系统预设，还没有玩家自定义保存多套构筑。
- 构筑强度预估已经有基础版，但还没有用真实跑测数据校准。
- 法宝、天赋、功法已有流派联动提示，但缺少更明确的组合收益解释。
- 本命法宝还没有在局内角色旁边形成持续可见表现。

## 后续计划

- 增加玩家自定义构筑保存与一键切换。
- 用跑测数据校准战备评分，避免“看起来可战但实战偏弱”。
- 增加组合收益说明，例如为什么某个法宝适合某章 Boss。
- 增加本命法宝在角色旁边的局内显示。

## 验收标准

- 更换本命法宝后入局属性变化。
- 更换功法后起手法术变化。
- 悟道蒲团升级能增加天赋槽。
- 锁定天赋不可选择。
- 套用系统预设后，已解锁的法宝、功法和天赋能同步更新。
- 入局预览能反映当前构筑的输出、生存和成长变化。
