# 01 运行载体与主题系统

## 目标形态

这个模块负责让同一套割草核心可以快速换皮、换数值、换文案。理想状态是新增一个主题时，只需要补主题配置、资产目录和少量专属规则，不改核心战斗逻辑。

目标体验：

- 默认打开就是修仙主题。
- 通过 URL 参数可以切换历史主题，用于回归测试和主题扩展验证。
- 主题之间共享核心战斗，但展示名、资源、敌人、武器、地图、文案、升级池都可配置。
- AI 生成图片只作为本地静态资源，运行时不依赖 image2。

## 当前实现

状态：已完成

当前入口：

- `demo/index.html`：页面结构、HUD、弹窗、洞府 UI 容器。
- `demo/src/main.js`：读取 URL 参数并选择主题。
- `demo/src/theme.js`：导出 `xianxia`、`office`、`cat` 三个主题。
- `scripts/serve-demo.mjs`：本地静态服务。

当前主题：

| 主题 | URL | 状态 | 说明 |
| --- | --- | --- | --- |
| 修仙 | `/` 或 `?theme=xianxia` | 默认 | 当前主线主题 |
| 打工人 | `?theme=office` | 保留 | 早期 Demo 备份 |
| 猫猫 | `?theme=cat` | 保留 | 早期 Demo 备份 |

## 数据与接口

主题配置核心字段：

| 字段 | 用途 |
| --- | --- |
| `name` | HUD 展示名 |
| `assetBase` | 静态图片资源目录 |
| `player` | 玩家初始属性和资源 |
| `enemies` | 怪物配置 |
| `weapons` | 武器配置 |
| `spells` | 修仙主题法术配置 |
| `equipmentSlots` | 局内装备槽配置 |
| `upgrades` / `equipmentUpgrades` / `fateUpgrades` | 局内升级池 |
| `waves` | 刷怪波次 |
| `pickups` | 拾取物 |
| `meta` | 修仙局外成长系统 |

当前 URL 参数：

| 参数 | 用途 |
| --- | --- |
| `theme` | 选择主题 |
| `chapter` | 调试指定章节 |
| `difficulty` | 调试指定难度 |
| `debugBoss=1` | 开局直接触发 Boss 调试 |

## 交互设计

- 玩家默认进入修仙洞府，不需要选择主题。
- 老主题只作为测试入口，不在 UI 中展示主题切换。
- 当主题没有 `meta` 时，不显示洞府局外成长，避免旧主题报错。

## 验收标准

- `/` 默认是修仙主题。
- `?theme=office` 和 `?theme=cat` 可正常运行。
- 主题图片缺失时旧主题不崩溃。
- 修仙主题局外 UI、战斗、结算能读到同一份 `xianxiaTheme` 配置。
