# 09 局外成长系统

## 目标形态

局外成长负责长期留存：玩家每局获得材料，回洞府升级，再进入更高章节和难度。

目标循环：

```text
战斗 -> 结算材料 -> 洞府升级 -> 构筑增强 -> 挑战更高章节/难度
```

## 当前实现

状态：MVP

当前成长线：

| 成长线 | 当前内容 | 消耗 |
| --- | --- | --- |
| 天赋树 | 剑修、灵修、体修、遁法、炼器，已接入 5/8/12 级里程碑效果 | 灵石 |
| 本命法宝 | 6 件法宝，10 级，已接入 3/6/10 级质变效果 | 灵石、玄铁 |
| 功法 | 4 本功法，5 级，已接入 3/5 级突破效果 | 道行、灵蕴 |
| 洞府设施 | 6 个设施，10 级，悟道蒲团支持 3/7 级天赋槽 | 灵石及部分材料 |
| 章节解锁 | 首通推进章节 | Boss 首通 |
| 难度解锁 | 凡境后解锁玄境，玄境后解锁天境 | 对应难度首通 |

当前辅助能力：

- 成长卡片会展示里程碑进度、下一里程碑收益和冲级成本。
- 材料不足时可以跳到材料页查看缺口。
- 结算后会给出下一步推荐，指向章节、开局或悬赏等局外目标。

## 数据结构

成长存档：

| 字段 | 用途 |
| --- | --- |
| `progression.talentTree` | 天赋树等级 |
| `progression.artifacts` | 法宝等级 |
| `progression.cultivations` | 功法等级 |
| `progression.facilities` | 洞府设施等级 |
| `unlocks` | 章节、难度、法宝、天赋、功法解锁 |
| `records` | 历史局数、章节记录、最高境界 |

## 当前缺口

- 里程碑效果已接入，但还缺少跑测校准，强度可能需要继续调。
- 成长路线已有基础推荐，但还没有形成“本周/本阶段目标”式长期路线。
- 没有重置或洗点机制。
- 没有满级后的追求。
- 洞府设施还没有外观升级差异。

## 后续计划

- 用跑测结果调整天赋树、法宝和功法里程碑强度。
- 增加阶段成长路线，例如先补输出、再补生存、再冲高难。
- 增加重置或洗点机制。
- 洞府设施外观升级。
- 增加满级后的追求，例如挑战章、称号或图鉴收集。

## 验收标准

- 战斗结算后资源增长。
- 升级会扣材料并保存。
- 刷新页面成长不丢。
- 首通解锁新内容。
- 到达里程碑等级后，局内属性或起手状态发生实际变化。
