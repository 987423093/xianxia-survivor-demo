# 01. 战斗成长系统

这份文档合并了原来的：

- 核心割草战斗
- 境界与局内升级
- 法术系统
- 局内装备系统

用于描述战斗内主循环和单局成长。

## 1. 当前范围

状态：已完成

当前已经落地的主链路：

- 玩家移动、自动攻击、受击、死亡、重开
- 普通怪、精英怪、Boss 刷新与追击
- 灵气珠、回血丹等拾取反馈
- 修为累计、突破三选一
- 法术成长与装备成长两条局内成长线
- 境界文本、境界形象与突破表现

主要代码：

- `web-runtime/src/gameplay/run-runtime.js`
- `web-runtime/src/gameplay/run-events.js`
- `web-runtime/src/gameplay/renderer.js`
- `web-runtime/src/content-registry/themes.js`

## 2. 战斗主循环

当前能力：

- 键盘与移动端虚拟摇杆移动
- 敌人从屏幕外生成并追踪玩家
- 自动武器按冷却索敌攻击
- 经验、掉落、伤害数字、受击和死亡反馈
- 死亡后进入结算，再回洞府或重新开局

主链路：

```text
开局 -> 刷怪 -> 自动攻击 -> 拾取 -> 升级 -> Boss -> 结算
```

## 3. 境界与突破

当前境界线：

- 炼气
- 筑基
- 金丹
- 元婴
- 化神
- 炼虚
- 合体
- 大乘
- 渡劫
- 飞升

当前能力：

- 等级显示为“境界 + 层数”
- 升级界面统一为“突破机缘”三选一
- 大境界切换时触发光效、文字浮现和短暂放大
- 主角会按境界切换基础形象

## 4. 法术系统

当前法术：

- 御剑成阵：基础索敌
- 业火莲华：近身范围伤害
- 雷符万钧：散射爆发
- 天劫雷瀑：灵力满后自动释放大招

当前能力：

- 法术可通过升级解锁和强化
- 法宝、功法、天赋树、装备会影响法术
- 灵力条独立驱动天劫雷瀑

## 5. 局内装备

当前装备槽：

- 法袍
- 法冠
- 靴子
- 护符
- 法器

当前能力：

- 每槽 0 到 3 阶
- 升级卡池会出现装备卡
- 装备会即时刷新角色外观和属性
- 装备按独立锚点分层渲染

## 6. 当前缺口

虽然主链路已完成，但以下仍然是增强项，不影响“完成”口径：

- 法术质变节点还可以继续扩
- 高境界的玩法差异还不够强
- 装备套装联动还没做
- 伤害来源统计还没进入正式结算页

## 7. 后续增强方向

- 给每个法术补更明确的强化分支
- 增加飞剑、火莲、雷符之间的组合收益
- 给高境界补被动差异，而不只换皮
- 增加装备联动和套装效果

## 8. 验收口径

- 能稳定开局、战斗、受击、死亡和结算
- 修为满后能弹出突破三选一
- 法术和装备升级都能即时生效
- 境界变化会同步到文本、形象和表现层
