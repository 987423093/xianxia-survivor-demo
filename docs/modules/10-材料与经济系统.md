# 10 材料与经济系统

## 目标形态

材料系统要让玩家知道“刷哪一章、为什么刷、刷完能升级什么”。它不是单纯显示数字，而是连接章节、Boss、设施、法宝和功法的经济骨架。

## 当前实现

状态：MVP

当前材料：

| 材料 | 定位 | 当前来源 | 当前用途 |
| --- | --- | --- | --- |
| 灵石 | 通用货币 | 击杀、存活、Boss、灵田加成 | 天赋树、法宝、设施 |
| 道行 | 修炼货币 | 境界、存活、Boss | 功法、藏经阁、悟道蒲团 |
| 玄铁 | 炼器材料 | 精英、Boss | 法宝、炼器炉 |
| 灵蕴 | 功法材料 | 突破、修为收集、Boss | 功法 |
| 雷纹 | 高阶材料 | 雷劫天门 Boss | 雷池 |

当前结算公式：

- 灵石：击杀、时间、Boss 奖励、章节/难度倍率、灵田加成。
- 道行：等级、时间、Boss 奖励、章节/难度倍率。
- 玄铁：精英击杀和 Boss 掉落。
- 灵蕴：突破次数、修为收集、Boss 掉落。
- 雷纹：雷劫天门 Boss 掉落。

当前 UI：

- 洞府已增加“材料”页，展示每种材料的来源、用途、近期需求和推荐刷图路线。
- 材料卡头部已接入图标字、名称、描述和独立余额显示。
- 每种材料会根据当前局外成长状态计算“总需 / 缺口”。
- 刷图路线会区分“首通待拿”和“复刷收益”，并显示按当前难度估算的单局产出。
- 缺口场景下会额外显示“约 N 局补齐缺口”，把推荐路线转成可执行目标。
- 材料页底部已增加章节收益预览，方便横向对比同难度的主要产出。
- 章节卡和 Boss 图鉴已展示主要掉落与首通奖励，把收益信息前置到主选择流。
- 结算页已展示奖励来源明细，拆出击杀、闭关、Boss、章节/难度倍率、灵田加成、奇遇和战场拾取。

## 数据结构

配置字段：

| 字段 | 用途 |
| --- | --- |
| `meta.currencies` | 材料名称和颜色 |
| `chapter.drops` | 章节 Boss 掉落 |
| `difficulty.rewardMultiplier` | 难度奖励倍率 |
| `upgradeCost()` | 局外升级消耗 |

运行字段：

| 字段 | 用途 |
| --- | --- |
| `metaState.currencies` | 当前材料数量 |
| `game.runStats` | 结算统计 |
| `calculateRunRewards()` | 计算本局奖励 |
| `addCurrencies()` | 增加材料 |
| `spendCurrency()` | 扣除材料 |
| `materialNeedAmount()` | 计算近期升级总需求 |
| `materialFarmRoute()` | 生成材料推荐刷图路线 |

经济节奏说明：

- 材料产出和升级成本最终要由 [13-数值管理模块.md](./13-数值管理模块.md) 给出目标周期，例如低级成长 1-2 局升一次，中级成长 2-4 局升一次。

## 当前缺口

- 目前的材料图标是轻量字标和 token，尚未补成独立章节掉落图标体系。
- 没有合成、兑换、商店。
- 没有局内实时材料掉落。
- 升级按钮旁还没有直接显示“缺这个材料建议刷哪章”，主要仍在材料页和结算推荐里承接。

## 后续计划

### P0：表现补齐

- 继续补齐章节掉落图标和 Boss 首通奖励图标。
- 升级按钮缺材料时直接显示推荐章节入口。
- 校准结算来源明细在移动端的可读性。

### P1：刷图目标

- 高难度显示额外材料倍率。
- Boss 首通奖励单独高亮。

### P2：经济深度

- 材料合成。
- 材料兑换。
- 局内小概率材料掉落。
- 商店或奇遇兑换。

## 验收标准

- 玩家能在 UI 中知道每种材料怎么获得。
- 玩家能知道升级缺什么材料。
- 玩家能知道刷哪个章节补材料。
- 玩家能大致预估补齐缺口还要刷几局。
- 结算页能解释本局材料来源。
- 章节选择和 Boss 图鉴里能提前看到主要掉落和首通奖励。
