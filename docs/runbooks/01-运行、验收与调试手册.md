# 01. 运行、验收与调试手册

这份手册是当前 Web Runtime 的唯一运行手册，收口以下三类信息：

- 怎么启动本地运行时
- 怎么做移动端验收
- 怎么做常用调试与问题排查

## 1. 本地运行

在仓库根目录执行：

```bash
npm run web-runtime
```

兼容入口仍保留：

```bash
npm run demo
```

### 1.1 默认地址

```text
http://127.0.0.1:6273/
```

### 1.2 常用调试入口

```text
/?theme=office
/?theme=cat
/?debugBoss=1
/?debugBoss=1&chapter=stone-array
/?debugBoss=1&chapter=blood-wasteland
/?debugBoss=1&chapter=thunder-gate&difficulty=heaven
```

## 2. 基础验证链

每次改动后，至少执行：

```bash
npm run config:check
npm run test:meta
npm run test:ui-assets
npm run test:mobile
npm run smoke
```

如果改动涉及图片资源，再补：

```bash
npm run assets:prepare
npm run assets:check
```

### 2.1 验证口径

- `config:check`：检查运行时接线和关键模块路径
- `test:meta`：检查章节、难度、奖励、元进度配置
- `test:ui-assets`：检查洞府 UI 资产协议
- `test:mobile`：检查移动端壳层和关键资源
- `smoke`：检查静态服务、主模块和关键路由

## 3. 移动端验收

当前项目只支持竖屏移动端。

涉及下列范围的改动，必须做浏览器级手机竖屏验收：

- `web-runtime/styles.css`
- `web-runtime/index.html`
- `web-runtime/src/main.js`
- `web-runtime/src/ui/home/*`
- `web-runtime/src/content-registry/themes.js`
- `web-runtime/assets/xianxia/*`

### 3.1 推荐视口

- `390 x 844`

### 3.2 必验页面

- 首页
- 更多页
- 图鉴页
- 战斗页

### 3.3 必验检查点

- 首页默认进入洞府，不回退到旧桌面布局
- `首页 / 构筑 / 悬赏 / 章节 / 更多` 导航可见
- 更多页标题、背景和入口分组正确
- 图鉴页背景和标题正确，不误用章节横幅
- 战斗页使用紧凑移动端 HUD
- 成长抽屉打开时，不遮挡 Boss 条和底部主按钮

## 5. 章节切换问题排查

如果遇到“弹窗切了章节，但首页主卡没变”：

- 先用 `http://127.0.0.1:6273/`，不要优先在 `file://` 下调试
- 点击 `更换`，确认弹窗真的打开
- 选择目标章节，确认 detail 面板章节文案变化
- 关闭弹窗后，确认首页标题和背景变量同步变化

### 5.1 优先排查文件

- `web-runtime/src/ui/home/actions.js`
- `web-runtime/src/ui/home/controller.js`
- `web-runtime/src/ui/home/renderers.js`
- `web-runtime/src/meta/progression/meta-store.js`

### 5.2 重点检查项

- 点击事件是否写回 `selected.chapterId`
- 渲染前是否有 `sanitize` / `normalize` / `fallback`
- 首页读取的状态和弹窗读取的状态是否同源
